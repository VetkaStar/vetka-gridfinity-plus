# Лендинг VETKA Gridfinity Plus

Лендинг входит в общий сайт проекта. Для локальной проверки соберите его по инструкции в [GITHUB-PAGES.md](../GITHUB-PAGES.md).

В `config.js` заданы общие ссылки для лендинга и генератора, включая Google Форму обратной связи.

Снимок `assets/generator.png` сделан с работающего генератора. При публикации сборщик копирует файлы лендинга в корень сайта.
