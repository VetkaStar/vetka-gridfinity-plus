# VETKA Gridfinity Plus

Автор проекта - [Vetka_Star](https://github.com/VetkaStar).

[Сайт проекта](https://vetkastar.github.io/vetka-gridfinity-plus/) · [Открыть генератор](https://vetkastar.github.io/vetka-gridfinity-plus/generator/)

Улучшенная независимая версия генератора ящиков Gridfinity Extended: русский и английский интерфейс, произвольные размеры корпуса, каркасные панели под склейку, фанерные вставки и компоновка нескольких корпусов.

Есть индивидуальные высоты ящиков, независимая перфорация, диагонали, полозья, ножки и ответные гнёзда, соединительные ключи. Настройки распределены по вкладкам со сворачиваемыми подразделами. Просмотр всей сборки отделён от печати: детали можно скрывать и раздвигать, STL и ZIP выбираются независимо. Для подбора посадки есть небольшие пробники, включая соединение дна со стенкой. Пресеты сохраняются в браузере и переносятся через JSON.

## Запуск

Нужен Python 3.12+ и современный браузер на Chromium. В Windows запустите `Запустить.cmd`. При первом запуске вычислитель OpenSCAD скачивается из официального источника с проверкой контрольных сумм, а сайт собирается из исходников. Локальный адрес: http://127.0.0.1:8342/.

Ручной запуск:

```sh
python bootstrap_runtime.py
python build_ru.py
python launch.py
```

Интернет также нужен для внешних библиотек интерфейса. В ячейках доступен цельный корпус; разборная панельная печать отмечена «Скоро». Панели в миллиметрах собираются под клей. Глубина корпуса не включает ручки. Физическая посадка зависит от принтера и материала: сначала печатайте небольшой пробник.

Комплект исходников OpenSCAD, библиотек, подмодулей, патчей и лицензий находится в [third_party/openscad](third_party/openscad/README.md). Проверка: `python prepare_openscad_sources.py --verify`.

Для подготовки готового сайта с вычислителем и скачиваемыми исходниками выполните `python build_release.py --output dist/publication`. Нужен Git и подготовленный состав исходников в его индексе. Папка `dist/publication` содержит сайт, страницу лицензий, оба архива исходников и контрольные суммы. Команда ничего не публикует и не пушит. Повторная компиляция самого OpenSCAD в Windows не проверялась; инструкция сборки для Linux с Docker включена в комплект.

Подробности разработки и тестов — в [README.md](README.md). Правила подготовки публикации — в [RELEASE.md](RELEASE.md).

Это сторонняя доработка, не официальный выпуск Gridfinity или OpenSCAD. Модель основана на [Gridfinity Extended](https://github.com/ostat/gridfinity_extended_openscad), веб-редактор — на [web-openscad-editor](https://github.com/yawkat/web-openscad-editor).
